# LAN Exam System Portable V0.1.0

这是一个面向非技术人员的小型 Windows 局域网考试系统。
- 源码包含：
  - `server.ps1`：PowerShell/.NET 局域网后端
  - `web/admin.html`：管理员端
  - `web/user.html`：成员端
  - `QUESTION_IMPORT_TEMPLATE.xlsx`：Excel 题目导入模板
  - `QUESTION_IMPORT_TEMPLATE.csv`：CSV 题目导入模板
  - `START_SERVER.bat`：Windows 一键启动脚本
- Windows PowerShell 5.1 兼容逻辑、自动防火墙处理、历史考试、人工改判、题目导入、重新测验等功能均保留。

## 启动

管理员只需要一个入口：

`START_SERVER.bat`

双击后系统会：

1. 自动检查 TCP 8080 的局域网防火墙规则；
2. 首次需要时自动请求 Windows 管理员权限添加规则；
3. 启动局域网考试服务；
4. 自动打开管理员后台；
5. 在窗口中显示成员访问地址。

成员电脑无需安装任何环境，只需使用 Edge / Chrome 打开管理员提供的局域网地址。

## 默认账号

- 管理员用户名：`admin`
- 管理员密码：`admin123`
- 默认考试口令：`123456`

建议第一次登录后修改管理员密码。

## 出题：单选、多选、图片和附件

管理员进入“新增题目”，可选择判断纠错题、主观题、选择题；选择题中再设置单选或多选。

- 选择题固定填写 A、B、C、D 四个选项，在正确选项前选择答案。单选使用圆形单选按钮，只能设置一个正确答案；多选使用复选框，至少设置两个正确答案。
- 成员答题时会显示“单选题 / 多选题”和操作提示。多选必须全部选对；少选、多选、错选均算错误。
- 选择题和主观题支持图片题干，可只上传图片而不填写正文，也可图文结合。截图内已有选项时，选项内容可以填写 A、B、C、D。
- 支持 PNG、JPEG、GIF、WebP 图片，以及 PDF、Word、Excel、TXT、CSV、ZIP 附件。每题最多 6 个文件，单文件最多 3MB，合计最多 6MB。保存前可预览图片、移除文件。
- 判断纠错题保持文字出题，不支持图片或附件。
- 历史复核和重新测验保留图片、附件及选择题选项。Excel 成绩导出包含选项、答案和文件名，不嵌入图片或附件内容。
- Excel/CSV 批量导入支持判断题、主观题、选择题（单选/多选）。图片附件请导入后在页面中添加。

文件独立保存在 `data/media`，通过随机文件地址访问。备份或迁移时请复制整个 `data` 目录；为保留历史引用，删除题目或移除附件不会自动删除磁盘文件。

修改后重启 `START_SERVER.bat`，刷新管理员和成员页面即可使用。

开发验证（Windows PowerShell 5.1）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/question-types.ps1
```

测试使用临时数据目录，不修改正式考试数据。


## 批量导入与下拉模板

请重新下载后台的 Excel 模板，或使用项目根目录的 `QUESTION_IMPORT_TEMPLATE.xlsx`。

- 固定字段提供下拉：题型、判断结果、作答方式、正确选项。正确选项根据单选/多选显示可用答案组合。
- 题目正文、四个选项、主观题标准答案自由填写。模板标题行已保护，输入区域可编辑；直接在 Questions 工作表第 2 行起填写自己的题目；示例单独放在“示例参考”工作表，无需删除，也不会导入。
- Excel 会阻止非法键入，但允许键入合法值；部分表格软件或粘贴操作可能绕过下拉规则，导入时服务端会再次校验并报告错误行。
- CSV 模板仅保留标题行，不含示例题；格式不能保存下拉和校验规则，推荐用 XLSX 填写。
- 导入时显示读取、上传处理和完成状态，防止重复点击。题目列表每页显示 50 道题。
- 文件最大 10MB。导入采用批量追加并统一保存；数据量较大时仍需等待处理完成。
- 旧版五列模板仍支持判断题、主观题。新版增加作答方式、选项A–D、正确选项列；选择题需填写四个选项。

验证导入及前端分页：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/import-questions.ps1
node tests/import-ui.cjs
```

维护模板时，可运行 `python tools/build_import_template.py` 重建 XLSX 和 CSV（仅使用 Python 标准库）。

请重新下载新版模板。旧版模板中混在正式数据里的示例题没有专用标记，仍会作为正式题目导入；新版通过独立的“示例参考”工作表避免误导入。
